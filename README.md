# LNU Graduation Transcript Printer

**辽宁大学亚澳商学院毕业成绩单批量打印工具**

A Tampermonkey userscript for batch printing graduation transcripts in Liaoning University's academic administration system.

专为辽宁大学亚澳商学院教务系统开发的毕业成绩单批量打印辅助工具，支持批量导入学号、自动跳转学生成绩单、配置打印项目、多份打印、进度管理及脚本自动更新。

## ✨ 主要功能

- **批量打印**：支持一次性导入多个学生学号，按名单顺序自动处理毕业成绩单。
- **毕业年月设置**：支持自定义毕业年份和月份。
- **打印份数设置**：可指定每位学生需要打印的成绩单份数，默认每人 3 份。
- **打印项目选择**：可分别勾选平均学分值、平均学分排名、GPA 绩点和 GPA 绩点排名。
- **打印间隔控制**：支持设置打印等待时间，避免连续操作过快。
- **手动确认选项**：可选择是否在每次最终打印前进行人工确认。
- **进度记录**：保存当前处理进度，支持暂停后继续操作。
- **悬浮控制面板**：支持收起和展开，并记住面板状态，减少对原网页的遮挡。
- **自动更新**：支持通过 Tampermonkey 的脚本更新机制获取后续版本。

## 📦 安装方法

1. 在浏览器中安装并启用 Tampermonkey 扩展程序。
2. 下载仓库中的 `lnu-grad-print.user.js`，或通过脚本的 GitHub Raw 链接安装。
3. 在 Tampermonkey 中确认安装并启用脚本。
4. 登录辽宁大学亚澳商学院教务系统。
5. 进入与脚本匹配的教务系统页面，确认右上角出现批量打印控制面板。

如果此前已安装旧版本，请避免同时启用两个相同用途的脚本，以免出现重复执行或面板冲突。

## 📖 使用方法

### 1. 设置毕业年月

在控制面板中输入毕业年份和月份。

例如：

- 年份：`2026`
- 月份：`6`

系统将根据输入的年月构建学生成绩单查询地址。

### 2. 设置打印份数和间隔

可自定义每位学生的打印份数，以及每次打印后的等待时间。

默认设置：

- 每位学生打印 3 份。
- 打印等待时间为 10 秒。
- 每次最终打印前需要手动确认。

实际设置应根据教务系统响应速度和打印设备情况进行调整。

### 3. 选择打印项目

支持以下四项：

| 打印项目 | 默认状态 |
|---|---|
| 平均学分值 | 不勾选 |
| 平均学分排名 | 不勾选 |
| GPA 绩点 | 勾选 |
| GPA 绩点排名 | 勾选 |

可以按照实际工作要求调整勾选项目。

### 4. 导入学生学号

在“学号列表”输入框中粘贴待打印学生的学号，支持每行一个学号，也支持空格、逗号或分号分隔。

例如：

```text
20220000001
20220000002
20220000003
```

以上学号仅为格式示例，并非真实学生数据。

### 5. 开始批量打印

确认设置后，点击：

**开始/继续批量打印**

脚本将依次执行：

1. 根据当前进度读取学生学号。
2. 自动打开该学生的毕业成绩单页面。
3. 打开成绩单打印选项窗口。
4. 根据设置勾选指定打印项目。
5. 触发最终打印操作。
6. 按设置的打印份数重复操作。
7. 处理下一位学生，直至名单结束。

> 建议正式大批量打印前，先使用“只测试当前页面打印一份”验证打印设置。

### 6. 暂停和继续

点击“暂停”可以停止后续批量操作。

脚本使用浏览器本地存储记录打印名单、配置和当前学生索引，刷新页面后通常仍可恢复这些信息。

如需从指定学生继续，可以手动调整“当前进度”。

**注意：** 进度从 `0` 开始，`0` 表示名单中的第一位学生。

暂停或异常中断时，当前学生的部分打印份数可能已经执行。继续前请核实实际打印情况，避免重复打印。

### 7. 收起控制面板

点击面板右上角的“－ 收起”按钮，可以将完整操作界面缩小为标题栏。

点击“＋ 展开”即可恢复。

收起状态会保存在浏览器本地存储中，页面刷新或跳转后仍可保留。

## 🔄 自动更新

本项目使用 Tampermonkey 的原生更新机制。

脚本元数据包含：

```javascript
// @version      1.3
// @updateURL    GitHub Raw 脚本地址
// @downloadURL  GitHub Raw 脚本地址
```

正式发布时，维护者需要将 `@updateURL` 和 `@downloadURL` 修改为仓库中实际可访问的脚本 Raw 地址。

后续发布新版本时：

1. 修改脚本代码。
2. 更新 `@version` 版本号，例如从 `1.3` 升级至 `1.4`。
3. 将新版本提交到 GitHub，覆盖原有脚本文件。
4. Tampermonkey 根据自身的更新检查设置识别新版本。

自动更新是否执行、何时执行，以及是否需要用户确认，取决于 Tampermonkey 的配置和网络环境。

## ⚠️ 注意事项

- 本工具仅适用于已获得相应权限的教务管理工作。
- 使用前必须正常登录学校教务系统，并确保具有相关成绩单查询与打印权限。
- 脚本不会绕过学校的身份验证或权限管理。
- 请勿将包含真实学生身份信息的名单、成绩单或浏览器存储数据上传至公开 GitHub 仓库。
- 本工具记录的“已完成”进度不等于打印机已成功输出全部纸质成绩单，重要工作请人工核对。
- 批量打印期间，尽量避免手动操作同一页面，以免影响当前流程。
- 浏览器本地存储被清理、脚本运行异常或系统页面变更后，进度和操作行为可能受到影响。
- 建议先以少量学生测试，再开展正式批量打印。
